Döda Kvarter, the zombie roguelike for both screens of the RG DS and RG DS Plus (ROCKNIXDS).

**On the handheld:** the game updates itself: **Settings > Game updates** on the title (with Wi-Fi on). Or over ssh, as
root: `/storage/.config/rocknixds/dodakvarter/update.sh install`. High scores and settings stay.

The game's update needs ROCKNIXDS 1.6.1 or later (its first self-updating version came with it); on 1.6, update
ROCKNIXDS first (**Updates & downloads > ROCKNIXDS**).

What's new: see `dodakvarter/README.md` and the ROCKNIXDS release notes. This release is a pre-release on purpose:
ROCKNIXDS's updater only takes ROCKNIXDS's own releases.
