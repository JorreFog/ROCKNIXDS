# ROCKNIXDS 1.5.10
**A flashable SD card image.** Installing ROCKNIXDS on a new card no longer needs ssh: flash one file, put the card in
the handheld, switch it on.

> **RG DS Plus owners:** your release and image are on **[v1.5.10-plus](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.5.10-plus)**.

## 💾 The image

**`rocknixds-v1.5.10-rocknix-20261001.img.gz`** (attached below). It is ROCKNIX 20261001's own image, set to boot this handheld, with this release on it.

1. Flash it to a microSD card with [balenaEtcher](https://etcher.balena.io/),
   [Raspberry Pi Imager](https://www.raspberrypi.com/software/) (*Use custom*) or
   `gzip -dc rocknixds-v1.5.10-rocknix-20261001.img.gz | sudo dd of=/dev/sdX bs=4M`. This erases the card.
2. Put the card in the handheld and switch it on. ROCKNIX grows the card to its full size and restarts, then
   ROCKNIXDS installs itself in about a minute, with no network, and the menu comes up on the Nintendo DS.

The install log is `/storage/.config/rocknixds-firstboot.log`. The image only carries ROCKNIXDS: ROCKNIX itself is
unchanged apart from which device tree it boots.

## Already on ROCKNIX?

Nothing changes for you: **Updates & downloads > ROCKNIXDS** in the menu, or over ssh as before:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

## Also in this release

- The installer can run from a local copy with no network (`RGDS_SRC`, `RGDS_REF`, `RGDS_DEPS`, `RGDS_FIRSTBOOT`),
  which the image's first boot uses. `RGDS_REF` now names the release for the update check even with `RGDS_SRC`.
- A fresh install starts the menu on the Nintendo DS instead of Favorites.
- To build the images yourself: `tools/image/build-image.sh` (no root needed).
