# ROCKNIXDS 1.6 for the RG DS Plus (draft)
**A game that gets stuck no longer needs a restart, the in-game menu is here for everyone, and the menu is back about a
second after you quit.** 1.6 is one release for both handhelds. On the Plus it brings everything since 1.5.12-plus:
- 1.5.13 beta 1's in-game menu and easier pixel font;
- fast switching that keeps the menu up during games;
- ds-fsr that fits the Plus's panels;
- a fresh card that opens on the DS;
- the recommended settings as the defaults;
- fixes for the reports since then.

> **Draft, not released.** Parts were tested on an RG DS Plus on 2026-10-05: fast switching, the empty library,
> ds-fsr at 3×, the in-game menu. What 1.6 adds on top is built and checked on a PC (see *What was tested*), not yet
> on the handheld.
>
> **RG DS owners:** your release is **v1.6**.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

## 🛟 A stuck game never needs a restart again

On 2026-10-05 a Plus froze right after Pokémon Black 2 loaded its resume state: the game stopped drawing and nothing
ended it. With *resume on quit* on, the exit hotkey only asks the game to save at its next frame, and that frame never
came. The handheld had to be restarted. Now:
- **5 s without a picture** (outside DraStic's own menu and the in-game menu): a red card says *The game stopped
  responding*. The exit hotkey then takes you to the menu at once, and the log records what every part of the game
  was doing.
- **20 s without a picture**: the game is closed, and the menu says why.
- **The exit hotkey always ends the game.** A second press, or a game that doesn't take the save within 3 seconds,
  quits at once (without a resume state). A held key still saves.
- **A game frozen solid** (even its display engine stuck) is ended from outside after 15 s, with the same message.
- **The likely cause is fixed.** The Plus keeps DraStic's main thread on a CPU of its own (1.5.10's smoothness fix).
  A thread DraStic created after that, after a state load for instance, inherited that one CPU and could wait
  forever for a thread that couldn't run. New threads now start on every CPU.

## 🎮 The in-game menu

New for stable users (testers have had it since 1.5.13 beta 1). Clicking the left stick (L3) during a game opens a
menu in ROCKNIXDS Pixel's look instead of DraStic's old one:
- Resume;
- Save and Load, with eight slots, a picture in each, and *Undo last load*;
- Quick settings: volume, brightness, a live microphone meter and *Blow*;
- DraStic's own menu;
- Quit.

The top screen shows the paused game, this session's play time, the last save and your latest achievements.
Pop-ups (achievements, volume, saves) are in the same style.

## ⏱️ Back to the menu in about a second, and it looks clean

Quitting a DS game no longer restarts EmulationStation. The menu stays up during the game and is back about a second
after you quit, whatever the size of your library (measured on a Plus: about 1.7 s).
- Between the menu and the game the screens are plain black: no terminal cursor, and no leftover frame of the start
  animation.
- The menu appears only once it is drawing again, on both panels.
- `/storage/.config/drastic/dsflip/fast-switch off` (over ssh) goes back to the old way.

## 🖼️ ds-fsr fits the Plus

The FSR shader drew all 1024×768 pixels of each panel: about 25 ms per frame, so it dropped every other frame. It now
draws 3× the DS screen (768×576), and the display scales that to the panel: about 14 ms per frame, which fits. ds-crisp
remains the light, sharp choice; the default needs no GPU at all.

## 🗂️ A fresh card opens on the DS

With no DS games yet, EmulationStation used to drop the DS. The menu then opened on Music Player and two empty
collections, and their placeholder hung the ready screen when tapped. Now:
- The DS stays listed and says **No games yet / Copy .nds files to roms/nds**.
- Collections say *Nothing here yet*.
- Collection names are capitalised (*Favorites*, not *favorites*).

## ⚙️ The best settings are the defaults

*Auto* is the best choice everywhere:
- the **Gengis Engine** renderer: the same picture as DraStic's renderer with about 12% less CPU work;
- the DS's own texture filter;
- the balanced power profile;
- threaded 3D.

A player who picked *DraStic* keeps it.

## 🏆 RetroAchievements without a connection

A login that gets no answer (no Wi-Fi yet, a DNS hiccup, a busy server) no longer deletes your saved login. It is
tried again in the background: after 15 s, 30 s and a minute, then every 2 minutes. You see one pop-up, *no
connection*, instead of *login failed* with nothing after it. The log names the network error and the server's
answer.

## 🧠 The menu stays light

On 2026-10-05 EmulationStation grew to 713 MB on a Plus (975 MB, no swap) until the system closed it, and the
handheld didn't answer for minutes. It hasn't happened since, and the cause isn't known yet. 1.6 makes sure it can't
take the handheld down again:
- Image memory goes back to the system when it is freed.
- The Pixel theme's picture cache has a size limit.
- The menu's memory is written to `es-mem.log` as it changes.
- Past half the handheld's memory (487 MB) while no game runs, the menu restarts by itself.
- Two quick launch requests start the game once, not twice.

## 🔤 An easier pixel font

In ROCKNIXDS Pixel's font, **5** no longer looks like **S**, **2** and **Z** are told apart, and **B** no longer
reads as **G** (issue #34).

## 🧩 From your reports

- **#36, #37:** the DS settings disappeared, and Tools and Music Player showed up in the system settings, when the
  options file was left broken. The file is now checked before it is replaced, and repaired or rebuilt from
  ROCKNIX's. The repair and its tests are now on the Plus line too.
- **#31:** zipped DS games get their RetroAchievements id from the background job too (in-game achievements worked
  since 1.5.2).
- **#26:** the in-game menu's *Blow* presses the fake microphone however `drastic.cfg` binds it. A real blow is still
  being looked into: see *Known issues*.
- **#32, #34, #35:** *View Game Media*, the Save State Manager and *Manual Scrape* fit on the bottom screen instead of
  spreading over both (TODO: confirm once the dialog fix lands).
- **#27:** drag on the game list's progress bar to scroll (with the current letter above it), and tap the arrows
  beside the shoulder labels (TODO: confirm once the engine change lands).

## 📶 Online play is not in 1.6

The 1.5.13 test build had a *wfc dns* option for Nintendo WFC replacement servers. It doesn't get past the game's own
Wi-Fi setup yet, so 1.6 neither shows it nor runs it. The work continues separately.

## Known issues

- **A real blow into the microphone may do nothing** (issue #26): the speaker reaches the microphone as loud as a
  blow, and the echo gate then holds its bar above any blow. The in-game menu's *Blow* is the way around it for now.
- **RetroAchievements:** softcore only.
- **Heavy stretches at 2× can still drop frames** in some 3D games.
- **Front-end music** plays only files you add: copy `.mp3` or `.ogg` files to `roms` > `music` (ROCKNIX ships none;
  issue #43).
