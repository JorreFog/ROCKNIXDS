# ROCKNIXDS 1.5.5
**Gengis Engine, half the input latency, and faster RetroAchievements.** A new 3D renderer for DraStic, a quicker
response to the buttons in the default power profile, achievements that no longer slow the emulation down, and
the battery next to the Wi-Fi in ROCKNIXDS Pixel. Tested on an RG DS and an RG DS Plus.

> **RG DS Plus owners:** your release is **[v1.5.5-plus](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.5.5-plus)**.
> The install command and the menu's updater pick the right one for you.

> **Coming soon: a flashable image.** A ready-to-flash `.img` file is in the works to make installing ROCKNIXDS
> easier. It is being tested now and will be released in the very near future.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

## 🐎 Gengis Engine

A new 3D renderer for DraStic's hi-res mode, built into SuperDrastic 0.4.0-beta.1. It draws the same picture as
DraStic, pixel for pixel, with about 20% less work in DraStic's 3D threads: on a 3D-heavy test scene that is about
a quarter less CPU per frame, and in Pokémon HeartGold 6-11% less. Turn it on under *Game settings > Per system
advanced configuration > Nintendo DS > 3D renderer > Gengis Engine*, or per game. *DraStic* stays the default.

With Gengis Engine, **3D texture filter** (nearest = the DS's own, bilinear, sharp bilinear) smooths textures, at
about twice the 3D cost.

## ⚡ Faster response

The default power profile, *balanced*, now keeps one finished frame waiting for the screen instead of two:
**half the input latency** (16.7 ms of queue instead of 33.3 ms), just as smooth. Measured with HeartGold at
1104 MHz on both handhelds.

## 🏆 RetroAchievements that don't slow the game

Checking achievements took about a fifth of DraStic's emulation thread in HeartGold. It now runs on its own thread:
only the memory reads stay on DraStic's, about 5% of it. Achievements unlock exactly as before (checked frame by
frame against the unmodified RetroAchievements code).

## 🕹️ ROCKNIXDS Pixel

- **The battery next to the Wi-Fi.** With *Show battery status > Icon and text*, the percentage and the battery icon
  sit on the left after the Wi-Fi ("78% 🔋"), and the ROCKNIXDS logo moves over to make room.

## 🛠️ Fixes

- **A game that hangs while starting no longer leaves white screens.** If DraStic gets stuck in the kernel and
  can't be stopped, the menu comes back after a few seconds and the details are kept in
  `/storage/.config/drastic/dsflip/stuck-*.txt`.

Thanks to everyone testing the builds and sharing performance logs.
