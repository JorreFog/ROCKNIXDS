# ROCKNIXDS 1.5.8 for the RG DS Plus
**RetroArch games and the bottom screen (#33).** GBA, SNES, N64 and the other systems RetroArch runs open on the top
screen again, the bottom screen's touch menu resumes the game, and touch works right after a reboot. Tested on an
RG DS Plus with Aladdin (GBA), EarthBound (SNES) and Bomberman 64 (N64).

> **RG DS (non-Plus) owners:** your release is **[v1.5.8](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.5.8)**.
> The install command and the menu's updater pick the right one for you.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

Reboot once after the update, so the touch fix below is in place from the start.

## What was wrong, and what changed

- **The game opened on the bottom screen.** When the bottom screen had focus as a game started (often the first
  game after a reboot), RetroArch opened there, behind ROCKNIX's touch menu, and the top screen stayed black.
  RetroArch now always opens on the top screen.
- **A tap paused the game for good.** Tapping the touch menu moved the focus from RetroArch to that menu, and
  RetroArch paused itself for losing focus. *Resume Game* only closed the menu, so the game stayed paused. RetroArch
  no longer pauses when it loses focus (`pause_nonactive` off). The touch menu still pauses it while it is open.
- **Touch went to the top screen after a reboot.** At boot, ROCKNIX tied the touchscreen to the screen that had
  focus, the top one under the two-screen menu. Taps on the bottom screen then reached neither the menu nor the touch
  menu until a DS game was played. ROCKNIXDS turns that step off, and RetroArch games undo it as well.

`--uninstall` puts ROCKNIX's touch setup and RetroArch's `pause_nonactive` back.

1.5.6 and 1.5.7 were RG DS-only releases. This is the next RG DS Plus release after 1.5.5-plus.
