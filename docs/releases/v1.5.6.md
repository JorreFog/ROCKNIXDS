# ROCKNIXDS 1.5.6
**Nintendo DS settings show again.** 1.5.5 hid every DraStic option on the Nintendo DS menu. This puts them back,
including 3D resolution.

> **RG DS Plus:** 1.5.5-plus already lists the 3D renderer on its own, so this hotfix is the RG DS release.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

## Nintendo DS advanced settings (#37)

1.5.5 added *3D renderer* and *3D texture filter* inside *Share performance logs*. The menu only reads an option's
own choices, so the 3D renderer was never listed. The next time the menu started, that options file was left with a
tag too many and no longer parsed, and EmulationStation does not fall back to ROCKNIX's copy. The file is the one
every system reads, so DraStic's settings were gone with the rest: shaders, resume on quit, the power profile, the
microphone, and the 3D renderer, both under *Game settings > Per system advanced configuration > Nintendo DS* and on
a game's own advanced options.

They are separate options again, on the Nintendo DS menu (Select on the system, and the same list on a game):
shader, microphone sensitivity, resume on quit, power profile, share performance logs, 3D renderer, **3D
resolution** (2× or 3×) and 3D texture filter. *System options* stays the advanced submenu. 3× is Gengis Engine's
scale; DraStic's own renderer keeps its usual 2× hi-res. Updating, or starting the menu again after this build is
installed, rewrites the file, including one that 1.5.5 already broke.

Thanks to **parth5991** (#37) for the report.
