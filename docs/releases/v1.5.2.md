# ROCKNIXDS 1.5.2
**A fixes release for 1.5.1**, from your issue reports. Microphone sensitivity works, zipped games earn
achievements, the keyboard and its button hints stay on the screen, and ROCKNIXDS Pixel's L3 jump, battery
percentage and system switching work as they should. Every fix was tested on an RG DS and an RG DS Plus.

> **RG DS Plus owners:** your release is **[v1.5.2-plus](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.5.2-plus)**.
> The install command and the menu's updater pick the right one for you.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

## 🎤 Microphone sensitivity no longer stops games from starting (#26)

1.5.1's fix was aimed at the wrong thing. With the sensitivity at low, medium or high, ROCKNIX's DS touch library
starts its own microphone code in every program it is loaded into, and that code crashes anything that isn't
DraStic. ROCKNIXDS's game launcher was a small script, so it crashed before the game started. The launcher is now
a tiny program the library can't load into, and the game gets the setting as before and listens to the mic. The
fallback launcher (`nodsflip`) also stops leaving the button mapper running after a game with the mic
on.

## 🏆 RetroAchievements for zipped games (#31)

A `.zip` was hashed as the zip itself, which RetroAchievements doesn't know, and the game's memory was searched
for the zip's header, so achievements couldn't work even with the right hash. SuperDrastic now reads the `.nds`
inside the zip for both, without unpacking it. `.7z` isn't supported: keep those games as `.nds` or `.zip`.

## ⌨️ The keyboard and the button hints

- **Text fields fit their box** (#28). EmulationStation's own picture for a focused text field carries a colour
  profile that ROCKNIX can't load, so the field was drawn as a bare white bar running off the screen (1.5.1's fix
  was for something else). ROCKNIXDS Pixel Light has its own text fields now, like Pixel Dark, and a picture that
  fails to load never draws a box that size again, in any theme.
- **The button hints stay on the top screen** (#30). They were measured against both screens at once, so a long row
  (the keyboard's) ran onto the bottom screen. Now they close up their spacing to fit, and leave out the last ones
  only if that isn't enough.
- **The button hints sit inside the top screen's frame** in ROCKNIXDS Pixel (#24, #30), instead of on its bottom
  border, in every menu: the main menu, a game list's options, a game's options, the keyboard.

## 🕹️ ROCKNIXDS Pixel

From the feedback on 1.5.1 in #27:

- **L3 jumps to the next letter.** It did nothing: the button has a different name on these handhelds.
- **Battery percentage with its icon**: with *Show battery status > Icon and text* it reads "78% 🔋" on the right.
- **No flicker when you change systems.** The first time a system showed, its "last played" card was drawn on the
  spot, which cost a frame, and its cartridge appeared a few frames after the card. The systems on either side are
  now made ready in the background.
- **The progress bar follows a held direction**: it stood still until you let go.

## 🎮 SuperDrastic 0.3.0-beta.5

The RetroAchievements fix above, and two clock control fixes: battery saver's top clock holds from the start of a
game (its sessions began at the menu's clock, up to 1992 MHz), and a game above its profile's top no longer see-saws
between clocks.
