# ROCKNIXDS 1.5.1 for the RG DS Plus
**A fixes release for 1.5**, from your issue reports and from the performance logs you shared. Heavy games stop
running below full speed, the microphone works again, savestates don't stall the game, and ROCKNIXDS Pixel gets
the navigation it was missing.

> **RG DS (non-Plus) owners:** your release is **[v1.5.1](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.5.1)**.
> The install command and the menu's updater pick the right one for you.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

## ⚡ Full speed in heavy games

The performance logs players shared from 1.5 (from RG DS units; the Plus has no uploader yet) showed heavy 3D games
at 2x, such as Pokémon Platinum with a shader, Call of Duty and The 4 Heroes of Light, running at 45-55 fps while the
CPU sat at a lower clock than they needed. The Plus's SuperDrastic already steps up when a game falls behind, but not
past its power profile's top clock, and a heavy game at balanced's 1416 MHz runs slow all session.

The **power profiles' top clocks are now soft**: a game that can't keep up at its profile's top gets more, and the
clock comes back down when it fits. **SuperDrastic 0.3.0-beta.4** does this, and ships in this release. The details
are in [`docs/perf-logs-1.5.md`](https://github.com/JorreFog/ROCKNIXDS/blob/v1.5.1-plus/docs/perf-logs-1.5.md).

## 🎤 Fixes

- **Microphone sensitivity no longer stops games from starting** (#26). The mic and the game's sound were opened
  at the same moment; now the mic waits for the sound.
- **Saving a state no longer slows the game down** ([SuperDrastic #2](https://github.com/JorreFog/SuperDrastic/issues/2)): the CPU goes to its top clock for the few
  seconds DraStic needs to save or load a state.
- **Canvas-DS and DII-ESS-AYE stop refreshing over and over** (#25). Every picture the art downloader sent made
  EmulationStation rebuild the whole game list; now it rebuilds once when they stop, and the downloader sends them
  together at the end.
- **Text fields fit their box** (#28): a long name no longer runs off the screen when the keyboard opens, and
  ROCKNIXDS Pixel Dark's text fields are dark with light text, so you can read them.

## 🕹️ ROCKNIXDS Pixel

From the requests in #27:

- **Battery percentage**: *User interface settings > Show battery status > Icon and text* now shows it on the
  top screen.
- **Still top screen**: *User interface settings > Still top screen (no rise or bob)* stops the top screen moving on
  every step.
- **Hold left or right** to keep moving, faster the longer you hold.
- **Up and down** jump five games in a game list. **L3** jumps to the next letter.

## 🎮 In a game (SuperDrastic)

From the requests in [SuperDrastic #3](https://github.com/JorreFog/SuperDrastic/issues/3):

- **Start + Select** or **Menu + Start**, held for half a second, quit the game (with your resume save, as the exit
  hotkey does).
- **DraStic's menu shows the time and the battery** on the top screen when it opens.

## Known

- **Misaligned options in a game's settings** (#24) couldn't be reproduced from the description. If it's still there
  in 1.5.1, a photo of which menu it is will help.
- Not in this release, from [SuperDrastic #3](https://github.com/JorreFog/SuperDrastic/issues/3): savestate previews in DraStic's savestate menu, and changing the shader
  while a game runs.
- These fixes were tested on a PC (the patched EmulationStation under a virtual display, SuperDrastic's governor in
  a simulation, the host tests). The first logs from 1.5.1 will show the governor change on real handhelds.
