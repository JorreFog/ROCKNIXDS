# ROCKNIXDS 1.5.11
**The SD card image now installs everything on its first start.** In 1.5.10's image the first start stopped after
the menu theme: the menu looked right, but DS games ran on stock DraStic and *Updates & downloads > ROCKNIXDS* didn't
work. This release's image (`rocknixds-v1.5.11-rocknix-20261001.img.gz`, attached below) installs all of ROCKNIXDS. Tested on an RG DS Plus: flashed,
first start, full install, updater working.

> **RG DS Plus owners:** your release and image are on **[v1.5.11-plus](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.5.11-plus)**. The RG DS image has the same fix but was only tested on the Plus.

**Flashed 1.5.10's image?** Connect to Wi-Fi and run the installer once over ssh (as `root`, password `rocknix`):

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

After that, updates work from the menu again. Installs over ssh were never affected.

See the [README's Get started](https://github.com/JorreFog/ROCKNIXDS#get-started) for flashing the image.

**Known issue:** until there is at least one DS game in `roms` > `nds`, the menu has a UI bug. It goes away once
you add a DS game and restart.
