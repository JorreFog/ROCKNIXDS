# ROCKNIXDS 1.5.9
**A faster Gengis Engine.** SuperDrastic 0.4.0-beta.2: about 5% less CPU than 1.5.5's Gengis Engine and 12% less than
DraStic's renderer in Pokémon HeartGold, with the same picture. **Measured and tested on an RG DS Plus only**: the
RG DS gets the same library, but it has not been tried on one yet.

> **RG DS Plus:** your release is **[v1.5.9-plus](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.5.9-plus)**.
> The install command and the menu's updater pick the right one for you.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

## 🐎 A faster Gengis Engine

SuperDrastic 0.4.0-beta.2 brings a newer Gengis Engine: leaner rasterizer kernels, and a compositor that puts the
3D layer onto the screen with NEON instead of DraStic's per-pixel loop. Measured on an RG DS Plus, Pokémon HeartGold
walking from the same savestate (CPU time per frame, whole emulator):

| | 1104 MHz | 816 MHz | fps at 816 MHz |
|---|---|---|---|
| DraStic's renderer | 30.7 ms | 45.3 ms | 50.6 |
| Gengis Engine in 1.5.5 – 1.5.8 | 28.3 ms | 41.4 ms | 51.6 |
| **Gengis Engine in 1.5.9** | **27.1 ms** | **39.2 ms** | **53.1** |

On the 3D stress test's heaviest scene at 1104 MHz it runs at 51 fps, where DraStic's renderer manages 33.

The picture is still DraStic's, pixel for pixel: checked in HeartGold (26,400 rendered bins compared, none differ;
2.4 million composited lines compared, none differ).

Turn it on under *Game settings > Per system advanced configuration > Nintendo DS > 3D renderer > Gengis Engine*, or
per game. *DraStic* stays the default.
