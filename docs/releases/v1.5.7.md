# ROCKNIXDS 1.5.7
**3D resolution is Auto or 2×.** 1.5.6 put 3× in that list before it was ready. This takes it out.

> **RG DS Plus:** this is the RG DS release. 1.5.5-plus is unchanged.

## Install or upgrade

From 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything older, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

---

## 3D resolution

*Nintendo DS > 3D resolution* (and the same row on a game) lists **Auto** and **2×**. Auto is left unset, so
Gengis Engine keeps its own scale. 2× sets that scale to 2. DraStic's own renderer ignores the setting.

3× is not a choice. A handheld that already saved 3× in 1.5.6 is put back to Auto the next time the menu
starts, and a game launch does not apply that saved 3×.
