# ROCKNIXDS 1.6.3 for the RG DS Plus
**Set the date and time by hand.** A hotfix on 1.6.2: ROCKNIX only sets the clock over Wi-Fi, so a handheld without
Wi-Fi kept a wrong date and time with no way to change it. The RG DS (non-Plus) has the same fix as
[v1.6.3](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.6.3).

## Install or upgrade

From 1.6 or 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything else, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

New SD card: the 1.6 image on the [v1.6-plus release](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.6-plus),
then update from the menu.

## 🕒 Date & time

**Main menu > System settings > Date & time** has everything about the clock on one screen:

- **Year, month, day, hour and minute.** Set them and go back: the clock changes at once and is saved to the
  handheld's hardware clock.
- **Time zone** and **Show clock in 12-hour format**, which used to sit in System settings.

With Wi-Fi connected the handheld takes the time from the internet and puts it back over a time set by hand; the
screen says so. If the time is off by whole hours, the time zone is what needs changing.

Everything else is 1.6.2-plus.

Tested on an RG DS Plus: date, time, the hardware clock, the time zone and the
Wi-Fi message.
