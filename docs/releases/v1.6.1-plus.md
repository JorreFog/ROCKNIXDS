# ROCKNIXDS 1.6.1 for the RG DS Plus
**Döda Kvarter 0.2: a difficulty setting, a lock-on button, and a game that updates itself.** Nothing else in
ROCKNIXDS changes from 1.6.

> **RG DS (non-Plus) owners:** your 1.6 is coming separately. Until then **v1.5.12** is your release.

## Install or upgrade

From 1.6 or 1.5: **Updates & downloads > ROCKNIXDS** in the menu. From anything else, ssh into the handheld as `root`
(password `rocknix`) and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JorreFog/ROCKNIXDS/main/install.sh | sh
```

New SD card: the 1.6 image on the [v1.6-plus release](https://github.com/JorreFog/ROCKNIXDS/releases/tag/v1.6-plus),
then update from the menu.

## 🧟 Döda Kvarter 0.2

- **Difficulty: Easy, Medium, Hard** (Settings > Difficulty; a run takes it when it starts). 0.1 was too hard, so the
  new default is **Medium**: the dead (and the bosses) hit 30% softer, have 20% less health, come 15% fewer to a
  round, and turn into runners and sprinters more slowly. **Easy** goes further (55%, 40%, 30% off). **Hard** is 0.1's
  game. The high score list marks each run E, M or H; the scores from 0.1 count as Hard.
- **Lock on: R2** (the right trigger). A press locks your aim on the nearest zombie in sight, a red marker round it;
  press again and it moves to the next nearest, and round again. Hold R2 to let go. When the one you're locked on
  falls, the aim moves to the nearest by itself. Walk anywhere and keep shooting it. The right stick or a touch on the
  top screen still aims where you point.
- **The buttons that moved**, to free R2: the grenade is on **L2**, and the bag is all on **SELECT**: a tap picks the
  next item, holding it uses it (or tap the bag on the bottom screen). Settings > Buttons changes any of it. Custom
  layouts from 0.1 go back to the new defaults once.
- **The game updates itself.** From now on a new Döda Kvarter doesn't need a ROCKNIXDS update: the title says when
  there is one (with Wi-Fi on), and **Settings > Game updates** downloads it, checks it, puts it in place and starts
  it. High scores and settings stay; a run saved in the old version doesn't carry over, and the row asks first. A
  ROCKNIXDS update never puts an older game back over a newer one.

## For developers

A game release is a `dodakvarter-v<version>` tag (the game's `VERSION`), published as a pre-release by
`.github/workflows/dodakvarter-release.yml` with `dodakvarter-<version>-aarch64.tar.gz` and its `.sha256`; the game's
`device/update.sh` takes the newest. Like the bank's, these never show up as ROCKNIXDS releases.

Tested on a PC: the game's tests (the rules, the bot playing whole runs and every boss under the sanitizers, a run saved
and loaded, the monkey), the updater end to end against a local release (a damaged download changes nothing), and the
RG DS build under qemu. Not yet tested on a handheld.
